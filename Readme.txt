 ■ はじめに
--------------------------------------------------
このゲームはあたたかくなる様の二次創作ゲームです。
ご本人様とは一切関係ありませんのでご迷惑を変えることのないようお願いいたします。


 
■ ゲーム概要
--------------------------------------------------
ジャンル: 異世界RPG
プレイ時間: 一時間程度
エンディング数: 二種

ライブ直前のある日、高生紳士が目を覚ますとそこは異世界だった...
メンバーたち全員を集めて元の世界に帰ろう！
という二次創作ゲームです。
 
 
■ 動作環境
--------------------------------------------------
ブラウザ
 
 
■ 遊び方
--------------------------------------------------
1. ダウンロードしたZIPファイルを解凍(展開)してください。
   ※ ZIPを解凍せずに実行すると、正常に動作しません。
2. フォルダ内の「Game.exe」(名前を変更した場合はそのファイル)を
   ダブルクリックして起動します。

 
[操作方法]
  決定      : Enter / Z / スペース / 左クリック
  キャンセル : Esc / X / 右クリック
  移動      : 矢印キー
メニューからキーコンフィグを変更できます。
